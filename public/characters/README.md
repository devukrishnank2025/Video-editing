# Your characters go here

Create one folder per character, for example `public/characters/host/`, with transparent
PNG or SVG body parts: `body`, `head`, `armLeft`, `armRight` and, optionally,
`mouthOpen` and `mouthClosed`.

See the main README → "Replacing assets → Characters" for the canvas sizes and
pivot points. If you leave `parts` out, the built-in placeholder puppet is used.
